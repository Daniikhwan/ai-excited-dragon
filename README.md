A Node program that draws one 1024x1024 PNG of an excited crochet baby dragon bursting out of an ornate gold frame — written to /output/entry.png. The dragon is a cute teal baby dragon with big glossy eyes, a wide open happy mouth, spread coral wings and little claws reaching toward the viewer, covered in a V-stitch crochet texture, on a deep teal background with golden light rays, confetti, sparkles and bubbles.

## Run it

```sh
node main.ts
# writes entry.png to $MAKEFUN_OUTPUT_DIR (or ./out)
```

## How it works

- `main.ts` — entrypoint plus a from-scratch PNG encoder (signature, IHDR, IDAT via node:zlib, IEND, CRC32). No image libraries, no network, no dependencies.
- `raster.ts` — a small software rasterizer: a supersampled RGB buffer, circles, ellipses, polygons, thick lines, rotated rectangles, sparkles and V-stitches, with alpha blending and a dragon mask.
- `scene.ts` — the composition: a deep-teal gradient with a golden radial glow, light rays, a tilted ornate gold frame (cracked, with flying shards), the baby dragon (head, muzzle, eyes, horns, wings, tail, arms, claws, feet), a crochet V-stitch texture over the dragon's body, confetti, sparkles and bubbles.
- Everything is generated by code — there are no image files in this repository. The output is deterministic: running `node main.ts` twice produces byte-identical PNGs.
